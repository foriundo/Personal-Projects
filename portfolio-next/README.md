# Portfolio Next

A minimal portfolio using Next.js 14, Tailwind CSS, Framer Motion, and next-themes.

## Setup

```bash
npm install
npm run dev
```

## Env (optional for real email sending)

```
SMTP_HOST=
SMTP_PORT=587
SMTP_USER=
SMTP_PASS=
CONTACT_TO=you@example.com
CONTACT_FROM=no-reply@example.com
```
